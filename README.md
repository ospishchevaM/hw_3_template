## Запуск и остановка

Для запуска программы на устройстве должен быть установлен Docker c Docker Compose. Необходимо создать файл `.env` по примеру `.env.example` и подставить нужные значения приветствия и порта, по которому будет происходить доступ к программе. Затем нужно запустить в терминале команду 
```bash
docker compose up -d --build
```
После запуска открыть адрес `http://127.0.0.1:P/`, где P - номер порта, установленного в `.env`. Чтобы остановить приложение, ввести команду 
```bash
docker compose down
```

Данные счетчика сохранятся и при следующем запуске он начнет увеличиваться с текущего значения.
